# 选题依据与交付边界

核对日期：2026-10-01。项目名：LD-Flex 面向小批量生产的可恢复分拣单元与虚拟调试平台。

## 为什么选这个题

工信部 2026 年发布的行动方案涉及端侧处理、工业数据联通、虚拟产线、故障调控和生产调度。这里选择其中可以用 500 元台架研究的具体问题：订单切换和故障交替出现时，怎样兼顾交期、动作成本和物料状态可信性。政策说明方向的重要性，不能代替项目的创新论证。

与纯电机调速相比，本项目需要把离散事件系统、嵌入式实时控制、优化调度和实验统计连起来，答辩可讨论的工程取舍更多。与完整视觉机械臂产线相比，两路重力滑槽减少加工与采购负担。摄像头、云平台、语言模型、昂贵工业 PLC 均不列为主线依赖。

## 可检验问题

- RQ1：相同工单和换向成本下，滚动调度能否改善加权迟交，代价是什么？
- RQ2：重复、丢失或迟到指令下，控制器是否会额外开闸？
- RQ3：入口漏检、走错出口、卡料、急停和主机断联能否触发正确停机？
- RQ4：复位后能否保持“旧任务不自动再次执行、未知物料先核实”的约束？
- RQ5：复用控制核心以后，哪些仿真结论可以迁移到实物，哪些必须重新标定？

## 本轮交付

电脑上的可运行工作台、共享 C 控制核心、STM32 可编译固件、对照实验、原始日志、阶段 Git、公开仓库所需文件、接线和测试手册。实物加工、传感器电平检查、舵机行程标定和真实性能数据由拿到硬件后完成。

两路装置一次只容许一个物料在通道里。排产系统给出“下一个需要人工放入的物料及路线”；操作者按显示选择对应物料。装置不识别颜色或型号，不把未部署的识别能力写进成果。仿真批量运行中的自动供料是明确的环境假设。

## 竞赛适配

优先考察全国大学生嵌入式芯片与系统设计竞赛的芯片应用赛道，以及学校认可的自动化系统类开放选题赛事。2026 年该赛作品提交和决赛已经结束；下一届芯片平台、企业赛题、组队条件和时间需要按正式通知核实。当前 STM32 台架是研发平台，不代表满足未来指定开发板要求。

全国大学生电子设计竞赛的限时题目应按当届题目现场完成；本项目可提供基础能力和模块积累，不能据此声称已经完成该赛题。
