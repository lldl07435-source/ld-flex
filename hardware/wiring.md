# 电气与接线

此设计为 5V 低压桌面教学台架。图纸和固件已按 STM32F103C8 寄存器接口编译核对，实物电平、极性和动作行程尚待验收。

| 部件信号 | STM32 引脚 | 接法 |
|---|---|---|
| 入口光电 OUT | PA0 | 低有效；无遮挡高，遮挡低；3.3V 电平 |
| A 路出口 OUT | PA1 | 同上 |
| B 路出口 OUT | PA2 | 同上 |
| 闸门舵机 PWM | PA6 / TIM3 CH1 | 默认 1000 μs 关闭、1600 μs 打开 |
| 分流舵机 PWM | PA7 / TIM3 CH2 | 默认左 1100 μs、右 1900 μs |
| 常闭急停回路 | PB0 | NC 触点接 GND；断线/按下为高，立即请求停止 |
| 本地确认按钮 | PB1 | NO 按钮接 GND；只在人工复位时按住 |
| USART1 TX | PA9 | 接 USB-TTL RX |
| USART1 RX | PA10 | 接 USB-TTL TX |
| SWDIO / SWCLK | PA13 / PA14 | 下载器接口；保留 |

所有信号参考地共地。舵机的 +5V 由独立合格电源提供，不能从控制板 3.3V 脚取电。板卡供电按具体最小系统板的电路说明接入；不要同时把两个电源直接并到同一 5V 电源端。USB-TTL 的 VCC 通常可以不接，只接 TX、RX、GND。

建议舵机供电入口放 470 μF 电解电容并配 100 nF 去耦，走线短，信号地和大电流回流路径尽量分开。电容极性必须正确。光电信号线与舵机电源线避免长距离紧贴并行。

PB0 是软件联锁输入。还应保留独立切断舵机 5V 的开关；二者不等同于符合工业标准的安全急停系统。断电时普通舵机会失去保持力，闸门机构要尽可能依靠重力回到关闭位置，不能宣称任意断电状态都能物理锁住物料。

固件对三个光电输入采用整体稳定 15 ms 后更新的滤波，急停输入直接读取。输入抖动或脉冲短于滤波时间可能漏检；应调整传感器位置、遮光片宽度或速度，记录最短有效遮挡时间。主循环和串口应答会产生延迟，响应上限必须上板测量。

## 通信

115200 baud，8 数据位，无校验，1 停止位。帧：`@seq,op,session,job,route*CRC16\n`，CRC 覆盖 @ 与 * 之间的 ASCII，MODBUS 多项式 0xA001，初始 0xFFFF。

操作：0 查询、1 人工 ARM、2 RUN、3 HEARTBEAT、4 STOP。route 0 左、1 右。job 是本次会话单调递增的执行编号，物料编号在上位机日志单独映射。seq 是本次通信应答编号，两者不能混用。

应答字段：`seq,result,session,job,state,fault,route,inputs,releases,completed,uptime`。状态和结果枚举见 `core/cell.h`，Python 解码见 `ldcell/protocol.py`。

STOP 总是可请求。ARM 需要物理按钮、传感器清空、急停解除、当前无活动动作。MCU 重启先锁定，上位机不会自动 ARM。重复 RUN 在同一会话、同一任务、同一路线下返回 DUPLICATE，不新增放料；跨重启依靠锁定、会话核对和人工清空处理，未使用非易失任务事务。

## 默认时序

对准 350 ms；闸门最多开 180 ms；通过等待 2500 ms；出口清空稳定 120 ms；有效心跳超时 700 ms。STM32 还有独立看门狗，LSI 偏差导致复位时长不精确。默认值见 `core/cell.c`，机械变化后必须重新标定。
